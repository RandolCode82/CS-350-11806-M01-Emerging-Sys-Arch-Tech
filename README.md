# CS-350-11806-M01-Emerging-Sys-Arch-Tech
Selected Artifacts

Artifact 1: GPIO Button and LED Control Program

This artifact demonstrates my ability to write interface software that allows hardware components to communicate with software. The program used GPIO pins on a Raspberry Pi to control LEDs and respond to button presses. It showcases my understanding of hardware interaction, event handling, and embedded systems programming.

Artifact 2: Final Smart Thermostat Project

This artifact demonstrates my ability to integrate hardware and software into a complete system. The project used LEDs, buttons, and a Raspberry Pi to simulate a smart thermostat interface. It highlights my skills in system design, hardware control, and creating maintainable code while meeting project requirements.

Project Summary

The purpose of this project was to design and implement a smart thermostat system using a Raspberry Pi and connected hardware components. The project solved the problem of creating an interactive embedded system that could respond to user input and provide visual feedback through LEDs. Along the way, I learned how software and hardware interact and how architectural decisions affect system performance and user experience.

What I Did Particularly Well

One of my greatest strengths during this project was persistence and troubleshooting. I encountered several challenges while wiring components, configuring GPIO pins, and debugging my code. Instead of giving up, I worked through each issue systematically until I found a solution. I also did a good job documenting my work and testing each feature individually before integrating everything into the final project.

Where I Could Improve

If I could improve one area, it would be spending more time on the initial design phase before writing code. While I eventually achieved the desired functionality, additional planning could have reduced some of the troubleshooting and rework later in the project. I would also like to become more comfortable with advanced embedded systems concepts and hardware debugging techniques.

Tools and Resources Added to My Support Network

Throughout this project, I relied on course materials, instructor guidance, Raspberry Pi documentation, and online technical resources. I gained experience using Python for hardware control, GPIO libraries, Linux commands, and debugging tools. Going forward, these resources will remain valuable references as I continue learning about embedded systems and emerging technologies.

Transferable Skills

Several skills from this project will transfer directly to future coursework and professional projects. These include:

Problem-solving and troubleshooting complex technical issues
GPIO programming and hardware-software integration
Reading and interpreting technical documentation
Testing and debugging software systematically
Designing systems that meet functional requirements
Managing projects through planning, implementation, testing, and refinement

These skills will be useful in software development, embedded systems projects, cybersecurity applications, and future computer science coursework.

Maintainability, Readability, and Adaptability

I worked to make my project maintainable and readable by organizing my code into logical sections, using descriptive variable names, and including comments to explain key functionality. I tested components individually before integrating them into the final solution, which made debugging easier. The design is also adaptable because hardware configurations and software functionality can be modified without completely rewriting the program. This modular approach will make future improvements and updates easier to implement.

Final Reflection

This project strengthened my understanding of how hardware and software work together in embedded systems. It gave me hands-on experience with Raspberry Pi development, GPIO programming, and system architecture concepts. More importantly, it reinforced the value of patience, persistence, and continuous learning when solving technical challenges. The skills and knowledge I gained from this project will be valuable as I continue pursuing my degree and preparing for a career in technology.
